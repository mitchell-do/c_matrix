# 🔢 S21 Matrix Library

[![GitHub last commit](https://img.shields.io/github/last-commit/mitchell-do/dota_bot)](https://github.com/mitchell-do/dota_bot/commits/main)
[![Language](https://img.shields.io/badge/language-C-blue.svg)](<https://en.wikipedia.org/wiki/C_(programming_language)>)

**S21 Matrix Library** — это высококачественная библиотека для работы с матрицами на языке C. Она предоставляет полный набор операций для создания, управления и выполнения математических вычислений над матрицами, включая сложение, вычитание, умножение, транспонирование, вычисление определителя, обратной матрицы и алгебраических дополнений.

---

## 📋 О проекте

Данный проект представляет собой реализацию библиотеки матричных операций, написанную на чистом C с акцентом на:

- **Надёжность** — тщательная обработка ошибок и проверка входных данных
- **Эффективность** — оптимизированные алгоритмы для матриц малых размеров
- **Чистоту кода** — модульная структура, подробная документация и тестирование
- **Производительность** — минимальное использование динамической памяти и оптимизированные циклы

## ✨ Основные возможности

### Базовые операции

- **Создание и удаление матриц** — выделение и освобождение памяти
- **Сравнение матриц** — проверка идентичности с учётом погрешности для `double`

### Арифметические операции

- **Сложение матриц** — поэлементное суммирование
- **Вычитание матриц** — поэлементное вычитание
- **Умножение на число** — масштабирование всех элементов
- **Умножение матриц** — стандартное матричное умножение

### Матричные преобразования

- **Транспонирование** — перестановка строк и столбцов
- **Вычисление определителя** — рекурсивный алгоритм разложения по строке
- **Матрица алгебраических дополнений** — построение матрицы миноров со знаками
- **Обратная матрица** — инвертирование через матрицу дополнений

## 🚀 Особенности реализации

### 1. 🎯 Оптимизация для малых матриц

```c
// Для матриц 1x1 и 2x2 используются специализированные алгоритмы
if (A->rows == 2) {
    s21_calc_complements_logic_double_matrix(A, result);
}
```

- **Матрицы 1x1** — результат равен единственному элементу
- **Матрицы 2x2** — дополнения вычисляются по прямым формулам без создания временных матриц

### 2. 🛡️ Надёжная обработка ошибок

```c
#define OK 0
#define ERROR_INCORRECT_MATRIX 1
#define ERROR_CALCULATION 2
```

Каждая функция возвращает код ошибки, позволяя легко отслеживать проблемы:

- Некорректные указатели (`NULL`)
- Несовместимые размеры матриц
- Вырожденные матрицы (нулевой определитель)

### 3. 📐 Чистая архитектура

Проект разделён на логические модули, каждый из которых отвечает за конкретную операцию:

- `s21_create_matrix` / `s21_remove_matrix` — управление памятью
- `s21_calc_complements` — алгебраические дополнения
- `s21_determinant` — вычисление определителя
- `s21_inverse_matrix` — обратная матрица

### 4. 🧪 Полное тестовое покрытие

Используя фреймворк **Check**, проект включает более **50 тестов**, покрывающих:

- Граничные случаи (матрицы 1x1, 2x2, большие матрицы)
- Ошибки ввода (NULL-указатели, неквадратные матрицы)
- Вырожденные матрицы и деление на ноль
- Тесты на утечки памяти (циклы из 1000 итераций)

## 📚 Что можно узнать из этого кода

### 🔍 Алгоритмы и структуры данных

- **Рекурсивное вычисление определителя** — разложение по первой строке с вычислением миноров
- **Построение алгебраических дополнений** — создание матрицы миноров с чередованием знаков
- **Обращение матрицы** — через формулу `A⁻¹ = (1/det(A)) * Cᵀ`, где `C` — матрица дополнений

### 💡 Приёмы программирования на C

- **Управление памятью** — корректное выделение и освобождение двумерных массивов
- **Обработка ошибок** — передача кодов ошибок через возвращаемые значения
- **Работа с указателями** — безопасная передача и изменение данных
- **Структуры данных** — создание модульных и переиспользуемых компонентов

### 🧠 Математические концепции

- **Миноры и алгебраические дополнения** — теоретическая основа для вычисления определителей и обратных матриц
- **Свойства операций** — проверка ассоциативности, коммутативности (для сложения)
- **Численная стабильность** — использование `EPS = 1e-8` для сравнения чисел с плавающей точкой

## 🔧 Установка и использование

### Требования

- Компилятор C (GCC, Clang)
- Make (опционально)
- Фреймворк Check (для тестирования)

### Сборка

```bash
git clone https://github.com/mitchell-do/dota_bot.git
cd dota_bot
make
```

### Пример использования

```c
#include "s21_matrix.h"

int main() {
    s21_matrix A, B, result;

    // Создание матриц
    s21_create_matrix(3, 3, &A);
    s21_create_matrix(3, 3, &B);

    // Заполнение матриц...

    // Умножение
    s21_mult_matrix(&A, &B, &result);

    // Вычисление определителя
    double det;
    s21_determinant(&A, &det);

    // Обратная матрица
    s21_matrix inverse;
    s21_inverse_matrix(&A, &inverse);

    // Очистка памяти
    s21_remove_matrix(&A);
    s21_remove_matrix(&B);
    s21_remove_matrix(&result);
    s21_remove_matrix(&inverse);

    return 0;
}
```
